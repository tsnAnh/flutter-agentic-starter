# Coding Patterns

* Future KMP code should avoid primitive obsession: prefer platform/library types, `enum class`, sealed types, `@JvmInline value class`, and Arrow `Either`/`Option` over raw primitives for finite or high-risk domain concepts.
* iOS MLX voice pipeline should reject zero/tiny audio and blank transcripts before ASR/LM inference to avoid Metal nil-buffer aborts.
* Until upstream MLX fixes Gather scalar-index Metal validation, rerun `iosApp/patch-mlx-swift-gather-metal-validation.sh` after SwiftPM package resets.
* iOS local voice pipeline should unload ASR/LM model objects after each note operation and save transcript fallback if note generation fails.
* iOS pull-to-record should use a whole-screen simultaneous drag guarded by the notes list scroll-top state, matching the HTML demo's `scrollTop > 2` behavior.
* iOS detail navigation should use `NavigationStack` route pushes for notes, not bottom-sheet detail presentation.
