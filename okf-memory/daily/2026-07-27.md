# Project Requirements

* The template identity is `Flutter Agentic Starter`, package `flutter_agentic_starter`, organization `Example`, and application ID `dev.example.flutteragenticstarter`.
* Signals 7 is the sole presentation state architecture; GetIt/Injectable, GoRouter, repositories, Dio, Hive, Freezed, and fpdart remain.

# Decision Changes

* Accepted a single breaking architecture cutover with no compatibility adapters or persisted authentication migration.
* Enabled `signals_lint` by moving to its compatible Injectable 3 and Freezed 4 prerelease generator line.
* Scope the `flutter-agentic-starter` skill to Flutter application implementation, Flutter tests, and app-platform integration; do not activate it for repository maintenance.

# Major Changes

* Removed the legacy presentation dependency stack and boilerplate base/state/event classes.
* Converted session, connectivity, offline queue, permissions, and Home to Signals.
* Reorganized Home into `data/domain/presentation` and added focused transition, cleanup, and widget tests.
* Rewrote project docs, agent rules, project skills, and setup-tool expectations for Signals.
* Expanded all native project-skill copies into a comprehensive Signals implementation guide and made the setup tool preserve scoped activation on rename.
