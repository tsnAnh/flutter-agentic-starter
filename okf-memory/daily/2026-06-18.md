# Coding Patterns

* OKF memory uses plain markdown concept files with YAML frontmatter and reserved `index.md` and `log.md` files.

# Human Style

* User wants this project memory system to capture coding patterns, human styles, project requirements, decision changes, major changes, and roadmap changes.

# Project Requirements

* Root `okf-memory/` is the project memory source of truth.
* Daily memory logs must record only new durable facts.
* Daily rollover is agent-managed at start/end of work.

# Decision Changes

* Category base files are preferred over a single consolidated base file.
* Rollover should be managed by a project skill, not by app runtime code or a new dependency.
