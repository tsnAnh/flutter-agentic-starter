# System Architecture

```text
Android Compose UI        iOS SwiftUI UI + AVFoundation/MLX
        |                       |
        +------ shared ViewModels
                        |
              Notes domain/use cases
                        |
                Note repository
                        |
              Data source: Room KMP storage
                        |
        Core services: cache, auth, analytics, permissions, logger
```

Shared code uses Clean Architecture:

- `core`: reusable infrastructure and platform-safe abstractions.
- Shared result/null boundaries use Arrow `Either` and `Option`.
- `features/<feature>/domain/models`: domain models.
- `features/<feature>/domain/repositories`: repository contracts.
- `features/<feature>/domain/usecases`: business use cases.
- `features/<feature>/data/datasources`: local storage and platform-safe data sources.
- `features/<feature>/data/repositories`: repository implementations.
- `features/<feature>/presentation`: KMP ObservableViewModel classes.
- `di`: Koin modules.

`features/notes` is the app feature:

- Domain models stay plain Kotlin.
- Room entities, DAOs, and mappers stay in the data layer.
- `NoteRepository`, `SaveVoiceNoteUseCase`, `ObserveVoiceNotesUseCase`, and `NotesViewModel` are shared across platforms.
- `AppDatabase` version 3 stores `voice_notes`, including generated checklist text.
- Android and iOS resolve shared ViewModels from Koin and keep UI platform-native.
- Room schema JSON files under `shared/schemas/` are migration history and are generated by Gradle.

Platform boundaries:

- iOS owns capture and local inference through Swift protocols: `AudioRecorderService`, `SpeechTranscriber`, `NoteDraftGenerator`, and `VoiceNotePipeline`.
- iOS records temp WAV files with AVFoundation, transcribes using `mlx-community/Qwen3-ASR-0.6B-4bit`, then drafts or revises title, summary, and checklist with `mlx-community/Qwen3.5-0.8B-MLX-4bit`.
- Android v1 only renders persisted notes. A later Android voice implementation should implement the same processing boundary and pass `VoiceNoteDraft` into shared Kotlin.
