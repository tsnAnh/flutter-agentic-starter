# Codebase Summary

`kmp-agentic-starter` is a native Kotlin Multiplatform starter.

- `shared`: Kotlin shared architecture, DI, core modules, and feature ViewModels.
- `androidApp`: Android app shell and Jetpack Compose screens.
- `iosApp`: SwiftUI app shell and screens.
- `tools/projectSetup`: Gradle-run setup wizard.

Important package: `dev.tsnanh.kmpagenticstarter`.
